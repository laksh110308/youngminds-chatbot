📌 How to embed this chatbot on your existing website

Simply copy the 3 lines below and paste them before the </body> tag on any HTML page.

1.  <link rel="stylesheet" href="static/chatbot.css">
2.  Paste the chatbot HTML block (toggle btn + chat window)
3.  <script src="static/chatbot.js"></script>

That's it — the widget works on any site: WordPress, Webflow, plain HTML, etc.
